Connect Google Calendar

The worker has no Google credentials yet. This is a one-time setup. Once connected, every dated task, roadmap phase, milestone and project next step is mirrored into a "Control Panel" calendar in your Google account.

  1. In Google Cloud Console, enable the Google Calendar API.
  2. Create an OAuth client ID of type Web application, with redirect URI http://localhost:8976/callback.
  3. On the OAuth consent screen, publish the app (it can stay unverified). In "Testing" mode Google expires the refresh token after 7 days.
  4. Run the helper script from the repo root:
    GOOGLE_CLIENT_ID=… GOOGLE_CLIENT_SECRET=… node worker/scripts/google-auth.mjs
  5. Approve access in the browser; the script prints a refresh token.
  6. Store all three on the worker:
    npx wrangler secret put GOOGLE_CLIENT_ID
    npx wrangler secret put GOOGLE_CLIENT_SECRET
    npx wrangler secret put GOOGLE_REFRESH_TOKEN
  7. Reload this page. Existing dated items are back-filled to Google automatically.
